# Проверки версии 2.0

72 теста прошли на Python 3.12 с подменой Telegram API.

- 33 проверки базовой модерации, экранирования, эмодзи, прав, лимитов и SQLite.
- 39 проверок редакции Комарики: овнер-доступ, старые кнопки, разрешённые чаты, бессрочный мут входа, повторный join, чужой токен, обычный /start, повторное подтверждение, бан по сроку, сохранность прав админа, повтор после отказа Telegram, оригинальные муты, внешний ручной мут, запрет размута до подтверждения.
- Проверка сохранения входа в файл SQLite, закрытия и повторного открытия базы.
- Статистика не считает один message_id дважды, редактирования и сообщения ботов.
- Ники меняют только собственное имя, топ не создаёт прямых упоминаний.
- Таблица администрации игнорирует игровые ники.
- Бонус раз в день, кормление с оплатой и интервалом, невозможность отрицательного баланса.
- Дуэли и брак требуют согласия адресата, кнопки другого чата и повторные нажатия отклоняются.
- Взаимность брака, подарки обоим супругам, подтверждение развода инициатором.
- Проверены сценарии входа через служебные сообщения и события chat_member.

Запуск: python -m unittest discover -s tests -v

Реальные сетевые операции и работа на BotHost не проверены, поскольку токен не предоставлен. Тесты не отправляют сообщений и не наказывают реальных участников.
