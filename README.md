# Bao Admin 2.0 | Комарики

Бот для @komariki_chatss: модерация, подтверждение входа через личку, ники, активность, выращивание Бао, дуэли, браки и подарки. Все настройки доступны только владельцам из OWNER_IDS. Администраторы Telegram сохраняют команды модерации по своим действующим правам.

## Установка и обновление на BotHost

1. Останови прежний процесс бота. Сохрани резервную копию папки data при остановленном процессе.
2. Загрузи содержимое папки bao-admin-komariki в корень проекта. Точка запуска: `python bot.py`.
3. Установка зависимостей: `pip install -r requirements.txt`. Python 3.12.
4. Укажи переменные окружения:

```env
BOT_TOKEN=токен_от_BotFather
OWNER_IDS=твой_числовой_ID
DATABASE_PATH=data/bao_admin.sqlite3
ALLOWED_CHAT_IDS=
```

Несколько владельцев перечисляются через запятую. Без OWNER_IDS бот не запустится. На локальном компьютере можно заполнить .env по образцу .env.example.

5. При первом запуске бот сам определит числовой ID @komariki_chatss. Если Telegram не разрешает username, впиши его реальный ID вида `-1001234567890` в ALLOWED_CHAT_IDS. Это только пример формата, не ID Комариков. Узнать ID можно командой /id в старой версии бота до обновления.
6. Добавь бота администратором супергруппы. Нужны права блокировки участников, удаления и закрепления сообщений. Бот должен получать сообщения и события участников.
7. Напиши боту в личку `/start`, затем `/owner`. Выбери группу, настрой правила, кнопки, эмодзи и таблицу администрации.

База предыдущей версии обновляется автоматически: старые варны, настройки, тексты и эмодзи сохраняются. Существующий собственный шаблон приветствия не перезаписывается. Если нужен новый стандартный, выбери «Тексты и эмодзи», затем сброс приветствия.

Старые группы вне разрешённого списка бот покинет. Список ID сохраняется в базе. ALLOWED_CHAT_IDS применяется только для первоначальной настройки, далее используй /allow и /disallow. Для выбранного чата нужен постоянный диск, чтобы не потерять проверки входа и игровые данные.

Один токен, один процесс. Не запускай одновременно старую и новую версию. Session String и AI API не нужны. Файл moderation.py является модулем, запускается только bot.py.

Docker:

```bash
cp .env.example .env
# Заполни токен, OWNER_IDS и при необходимости ALLOWED_CHAT_IDS
docker compose up -d --build
```

Сохраняй прежний том базы. При переносе Compose-проекта под другим именем Docker может создать новый том: явно подключи старый том или перенеси резервную копию базы. Не используй down -v при обновлении.

## Стартовый экран и выбранные чаты

В личке короткая инструкция по установке и сообщение, что бот создан для @komariki_chatss. Кнопки: «Добавить в свой чат», «Инструкция по установке», «Команды». Кнопку овнер-меню видят только владельцы.

Добавление через публичную кнопку не выдаёт разрешение на работу в чужом чате. Бот сообщает, что работает только в Комарики чатс, и выходит из группы вне списка.

Только владельцу в личке:

```text
/allow -1001234567890
/allowed
/disallow -1001234567890
```

Можно выбрать до 20 групп. По умолчанию выбирается только @komariki_chatss. Перед добавлением в другую группу сначала разреши её ID. Удаление из списка блокируется, если в группе есть незавершённые проверки входа, чтобы не оставлять новичков с мутом после выхода бота.

## Овнер-меню

`/owner` и `/admin` открывают одну консоль. Любые настройки, старые inline-кнопки, изменение текстов, каталога эмодзи, ссылок, лимитов и таблицы администрации требуют OWNER_IDS. Обычная Telegram-админка этого доступа не даёт.

Доступны старые переключатели антифлуда и ссылок, тексты, эмодзи, лимиты, журнал и проверка прав. Дополнительно:

- кнопки и ссылки приветствия;
- уровни в таблице администрации;
- список ожидающих подтверждения входа;
- разрешённые группы;
- режим техработ `/maintenance on` и `/maintenance off`.

Ручная модерация продолжает проверять реальные права Telegram, даже у владельца бота. Владелец, который не администратор группы, может менять оформление, но не получает автоматически право наказывать её участников. Для изменения лимитов и включения соответствующей защиты также нужны права ограничения или удаления сообщений.

Проверка входа и её таймеры продолжают работать при отключении автоматических функций группы и в режиме техработ. Эти режимы не должны оставлять уже замученных новичков без возможности подтверждения.

## Вход в чат

1. При новом входе обычного участника бот выдаёт бессрочный мут. Это корректный эквивалент «миллиарда лет» в Telegram.
2. Бот пишет: «Чтобы зайти в чат, надо написать /start в ЛС боту» и показывает кнопку подтверждения.
3. Кнопка открывает личку бота. Нужна отправка /start, а не просто открытие окна лички. Обычный /start без ссылки также подтверждает текущую проверку этого пользователя.
4. Чужая ссылка не подтверждает вход другого человека.
5. После подтверждения возвращаются стандартные права группы. Отдельные наказания модераторов не снимаются.
6. Появляется приветствие с названием чата, командами /rules и !бао правила. Сверху кнопка «Правила», под ней «Администрация» и «Список команд бота».
7. Если участник остаётся в чате и не подтвердился за 24 часа, он получает бан. Проверки и срок сохраняются в SQLite. После рестарта просроченные проверки обрабатываются снова. При недоступном Telegram или снятых правах исполнение откладывается до восстановления доступа.

Подтверждение применяется только к новым входам. Существующие участники не получают массовый мут при обновлении. Участники-боты и администраторы не проходят эту проверку. Добровольно вышедшие перестают ожидать проверку; при новом входе она начинается снова.

Муты, существовавшие до проверки, сохраняются и восстанавливаются. Если модератор меняет ограничения во время проверки, бот не снимает их автоматически. В таком случае после /start отдельный мут может остаться, его должен снять администратор. До завершения проверки обычные /mute, /warn и /unmute через Bao Admin отклоняются; /ban остаётся доступен.

Бот должен быть онлайн и иметь права. После запуска сначала проверь вход тестового аккаунта, подтверждение и приветствие в разрешённой тестовой супергруппе.

## Кнопки, правила и премиум-эмодзи

В овнер-меню выбери группу, затем «Кнопки и ссылки». Отправь одну настройку:

```text
verify 5368324170671202286
rules 5368324170671202286
admins 5368324170671202286
commands 5368324170671202286
url https://t.me/your_rules_post
```

ID выше является примером. Укажи свои ID. Ключи: verify - подтверждение входа, rules - правила, admins - администрация, commands - список команд. Снять иконку: `verify off`. Убрать внешнюю ссылку: `url off`, тогда правила открываются в личке бота. После каждой настройки ввод завершается; для следующей снова открой кнопку.

ID премиум-эмодзи: `/emojiid` ответом на сообщение с ними, в том числе в подписи к медиа. Можно также прислать эмодзи рядом с командой.

Для эмодзи в предложениях сохрани каталог в меню или командой в личке после выбора группы:

```text
/emoji add bao 5368324170671202286
/text welcome {emoji:bao} Добро пожаловать в {chat}, {user}! Прочитай /rules или !бао правила и общайся!
```

В редактор можно просто отправить сообщение с настоящими премиум-эмодзи. Они сохранятся. Вставки: {user}, {chat}, {admin}, {reason}, {duration}, {count}, {limit}, {emoji:имя}. Длинные тире заменяются на дефис.

Telegram разрешает кастомные эмодзи ботам при Premium у владельца или дополнительном username на Fragment. Если Telegram отклонит кастомную иконку, кнопка отправится без неё; для текста используется обычная эмодзи-замена.
Источник: https://core.telegram.org/bots/api#inlinekeyboardbutton

## Ники, профили и актив

```text
!бао ник "Дядя Бао"
!бао ник
!бао ник сброс
!бао профиль
!бао топ
!бао топ день
!бао топ неделя
```

Без аргументов ник показывается свой; ответом на сообщение показываются ник и ID его автора. Установка ника меняет только собственный ник. Лимит 32 символа, ссылки и управляющие символы запрещены.

В топе используется игровой ник, если его нет - обычное имя Telegram. Ссылки ведут на карточку участника внутри бота. В тексте нет @упоминаний и tg://user-упоминаний, отправка тихая. В карточке есть отдельная ссылка на аккаунт, если у человека есть публичный username.

Топ показывает 15 участников и общее число сообщений за выбранный период. Считаются текст и медиа, включая команды. Служебные события, сообщения ботов и редактирования не добавляют актив. Повторная доставка одного message_id не увеличивает счёт. Удалённые после получения сообщения остаются в статистике. Старую историю до установки Bot API не выдаёт, счёт начинается с получения сообщений этой версией.

День определяется по Москве. «Неделя» означает сегодня и шесть предыдущих календарных дней.

## Таблица администрации

`!бао админы` или кнопка «Администрация»:

- 5 звёзд: Дяди Бао;
- 4 звезды: Старшие админы;
- 3 звезды: Младшие админы;
- 2 звезды: Старшие модераторы;
- 1 звезда: Младшие модераторы.

Всегда используются реальные имена Telegram, игровые ники здесь игнорируются. По умолчанию владелец группы получает 5 звёзд, администраторы 3. Онлайн-статусы не выдумываются, Bot API их не предоставляет.

Изменение только владельцем: овнер-меню, группа, «Таблица админов», затем `ID уровень`, например `123456789 4`. Уровень 0 скрывает человека. Можно добавить участника как модератора в таблицу, но это не назначает ему права в Telegram. Бот читает реальные права отдельно. Вышедшие не показываются.

## Питомец Бао

`!бао растить`, `!бао питомец`, `!бао кормить`.

Пять стадий:

1. Сын дяди Бао, 0 роста.
2. Повзрослевший сын дяди Бао, 60 роста.
3. Взрослый дядя Бао, 180 роста.
4. Старый сын дяди Бао, 420 роста.
5. Легендарный прабао, 800 роста.

Текстовая карточка «Жиробасинка Бао» показывает стадию, рост, условный вес, кормления и монеты. Кормление стоит 15 монет, даёт 12 роста и доступно раз в 4 часа. Питомец не умирает от отсутствия игрока. Вес является игровой характеристикой.

`!бао бонус` выдаёт 100 монет один раз за календарный день по Москве. Монеты только игровые, покупок за деньги нет.

## Дуэли, брак, подарки

Ответом на человека:

```text
!бао дуэль
!бао брак
!бао подарок роза
!бао совместимость
```

Дуэль и брак требуют кнопки согласия именно от приглашённого. Другие участники не могут принять за него. Приглашение действует 10 минут, инициатор может его отменить. Отказ доступен приглашённому. Не чаще одного приглашения за 2 минуты.

Дуэль случайно выбирает победителя. Победитель получает 15 монет, второй участник 5. У обоих час отдыха до следующей завершённой дуэли. Повторное нажатие не даёт повторной награды. Ставок и потери монет нет.

`!бао семья` показывает партнёра, дни вместе, подарки и статус отношений. Только один брак одновременно. После согласия зелёная свадьба и молодожёны. Через 7 дней бумажная, 30 серебряная, 100 золотая - игровые сроки. Пять подарков супругу дают «Тёплые отношения», двадцать - «Неразлучные Бао».

`!бао развод` создаёт отдельное подтверждение для инициатора. Игровой брак можно расторгнуть самостоятельно; второй участник не может нажать кнопку за инициатора.

`!бао магазин`: рыбка 15, роза 30, торт 60, кольцо 100, корона 250 монет. Подарок списывает монеты у дарителя и сохраняется в истории; супругам добавляет очко отношений. Кольцо само по себе не заключает брак, нужен отдельный запрос и согласие.

Ещё: `!бао монетка`, `!бао шар вопрос`, ежедневная шуточная совместимость. Для игровых команд есть короткий интервал в 3 секунды против спама. Игры, статистика и отношения разделены по группам.

## Модерация

Сохранены /warn, /warns, /unwarn, /mute 30m, /unmute, /ban, /unban, /del, /pin, /unpin, /rules, /report. Команды наказаний ответом или с числовым ID. Русские сокращения: бан, разбан, мут, размут, варн, пред, преды. Произвольный @username в качестве цели не разрешается, используй ответ или ID.

Для наказаний нужны права ограничения участников, для удаления и закрепления соответствующие права. Администраторы защищены. /unban не выкидывает уже находящегося в группе человека. /unmute возвращает стандартные права группы.

Антифлуд и запрет ссылок по умолчанию выключены. Варны: три предупреждения дают мут на час. Лимиты меняются через меню. Автоматическая модерация не наказывает администраторов. /report ответом на сообщение уведомляет админов, не чаще раза в минуту от одного пользователя. В отличие от топа, жалоба намеренно упоминает администрацию.

## Проверки и ограничения

72 автоматических теста выполнены успешно. Проверяются старые команды, права доступа, новые игры, деньги, согласие, повторные кнопки, вход, срок, восстановление из SQLite, обработка отказов Telegram и сохранение отдельных мутов.

```bash
python -m unittest discover -s tests -v
```

Тесты используют имитацию Telegram API. Реальный запуск с токеном, доставка премиум-эмодзи и BotHost не проверялись. Отсутствие сети и прав может задержать действия. Перезапуск сохраняет уже зарегистрированные проверки, но не даёт доступа к обновлениям, которые Telegram больше не хранит.

Сетевые изменения не повторяются автоматически после неопределённого таймаута, кроме идемпотентных стадий проверки входа. После сбоя модерации сначала проверь состояние участника. Update ID сохраняется перед обработкой, поэтому авария до записи нового события может привести к его пропуску; запущенную проверку защищает отдельное состояние в SQLite.

Хранятся ID, имена, игровые ники, счётчики сообщений, игровые данные, настройки и журнал модерации. Полный текст переписки не сохраняется. Существующие данные не удаляются при обновлении. Лицензия кода MIT.
